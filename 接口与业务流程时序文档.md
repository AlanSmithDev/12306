### 2.2 详细步骤

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 前端提交注册表单 | username、password、realName、phone、mail |
| 2 | Gateway路由到UserService | `/api/user-service/register` |

| 9 | 更新布隆过滤器 | 标记用户名已存在 |
| 10 | 用户名入可复用集合 | 用于注销后用户名复用 |

```java
// UserRegisterServiceImpl.register()
public void register(UserRegisterReqDTO request) {
    // 1. 责任链参数校验
    userRegisterChainContext.filter(request);
    
    // 2. 布隆过滤器检查
    if (bloomFilterDatabaseFallback.contains(request.getUsername())) {
        throw new ClientBizException(USER_NAME_EXIST);
    }
    
    // 3. 分布式锁
    RLock lock = redissonClient.getLock("user_register_lock:" + request.getUsername());
    try {
        // 4. 唯一性检查
        checkUserNameUnique(request.getUsername());
        checkPhoneUnique(request.getPhone());
        checkMailUnique(request.getMail());
        
        // 5. 写入数据库
        // ... 插入逻辑
        
        // 6. 更新缓存
        bloomFilterDatabaseFallback.add(request.getUsername());
    } finally {
        lock.unlock();
    }
}
```

### 5.3 令牌桶扣减Lua脚本

```lua
-- key: ticket:token:{trainId}:{fromStation}:{toStation}:{seatType}
-- args[1]: 扣减数量（通常为1）

local key = KEYS[1]
local count = tonumber(ARGV[1])

-- 检查令牌是否足够
local current = tonumber(redis.call('HGET', key, 'count') or 0)
if current < count then
    return -1  -- 余票不足
end

-- 原子扣减
redis.call('HINCRBY', key, 'count', -count)
return current - count  -- 返回剩余数量
```

| 8 | 返回支付表单 | 前端唤起支付 |
| 9 | 用户完成支付 | 跳转支付宝页面 |
| 10 | 支付宝回调 | POST异步通知 |
| 11 | 更新支付状态 | t_pay表status=已支付 |
| 12 | 发送MQ消息 | RocketMQ通知订单服务 |
| 13 | 订单服务更新状态 | t_order表status=已支付 |
| 14 | 前端轮询结果 | 查询支付状态接口 |

### 6.3 支付策略模式

```java
// 支付策略接口
public interface PayStrategy {
    /**
     * 构建支付请求
     * @param payRequest 支付请求参数
     * @return 支付参数（用于唤起支付）
     */
    PayVO buildPayRequest(PayRequest payRequest);
    
    /**
     * 处理支付回调
     * @param callbackData 回调数据
     * @return 处理结果
     */
    PayCallbackRespVO doCallback(Map<String, String> callbackData);
}

// 支付宝策略实现
@Component
public class AlipayStrategy implements PayStrategy {
    @Override
    public PayVO buildPayRequest(PayRequest payRequest) {
        // 构建支付宝支付参数
        AlipayTradePagePayRequest request = new AlipayTradePagePayRequest();
        request.setBizContent(JSON.toJSONString(new BizContent()
            .setOutTradeNo(payRequest.getOrderSn())
            .setProductCode("FAST_INSTANT_TRADE_PAY")
            .setTotalAmount(payRequest.getTotalAmount())
        ));
        // 调用支付宝SDK
        return alipayClient.pageExecute(request).getBody();
    }
}
```
